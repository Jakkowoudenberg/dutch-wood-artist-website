Jakko OS · Google Drive connection

Privacy notice

Updated 21 September 2026. This notice covers the private Jakko OS Google Drive connection operated by Jakko Woudenberg, Dutch Wood Artist, Schagen, the Netherlands. It supplements the website privacy policy.

Information processed and purpose

The connection processes the names, identifiers, metadata and contents of Google Drive files authorised for use with Jakko OS. These are used to find working documents, answer the owner's questions, prepare project and content drafts, and save requested changes. Google's drive.file permission limits access to app-created files and files selected for this app; it does not give unrestricted access to the entire Drive.

AI processing and service providers

Jakko OS runs through Grok Bot and its configured AI and tool services. When an agent reads a selected document for a task, relevant content may be included in that agent's context and processed by the configured AI service. Google provides Drive and account authorisation. Netlify hosts these public information pages; the pages themselves do not retrieve Drive files.

Do not select material for an AI task unless you are authorised to process it using the configured services. The applicable service terms and privacy settings must be considered before processing confidential or third-party personal information.

Access and storage

Google authorisation tokens are retained in the connection's runtime so it can renew access without asking for a password for each task. Working outputs remain in the selected Drive location. Agent conversations, execution reports and recovery copies may also contain task content in the Jakko OS environment. These records are separate from the public website.

Use limits

Google user data is used to provide the requested workspace features, not sold or used for advertising. Use and transfer of information received from Google APIs must comply with the Google API Services User Data Policy, including its Limited Use requirements. Google user data must not be used to train general-purpose AI models. Provider settings must support these limits before data is sent for processing.

Retention and deletion

Authorisation tokens are kept while the connection is in use. Working documents are kept until the owner removes them. Copies in agent history, reports or backups need to be removed separately; disconnecting Google alone does not delete those copies. Retain task records only while needed for the work and recovery, and review them when a project ends.

Remove access or request help

You can revoke Jakko OS access using Google Account connections. The connection may appear under the older name James. Revoking access stops future authorised API access; it does not delete existing Drive files or previously retained copies. Contact dutchwoodartist@gmail.com for access, correction or deletion requests and assistance removing runtime credentials or retained task records.

Where applicable, you may exercise your data-protection rights and contact the Dutch Data Protection Authority.
