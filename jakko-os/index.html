Jakko OS

Jakko OS is the private working environment of Jakko Woudenberg, Dutch Wood Artist. It helps organise project information, prepare content and keep selected working documents up to date.

This page explains the Google Drive connection. It is not a public sign-up service and does not display files from Google Drive.

What the Drive connection does

Authorised Jakko OS agents can read, create and update working files to carry out the owner's instructions. The connection uses Google's limited drive.file permission: it can access files created through the app and existing files explicitly selected for use with the app.

Existing files are selected using Google's file picker. Selecting one file does not grant access to every file in Drive. Agents can update an authorised file while keeping the same file and link.

Who uses it

The connection is for Jakko Woudenberg and explicitly authorised collaborators working within Jakko OS. It is not offered as a public product. The Google project was originally named James; that name may still appear during sign-in.

Your information and control
